BANKING FINANCIAL PORTAL.
Project moto:
   - to provide online banking services.
   - It offers services like  Account creation, Amount transfer, bill payments, 24/7 customer support.
Technologies used:
    --HTML (Frontend)
    --Python Flask (backend)
    --SQlite3 (Database)
Execution Process:
  1. run database.py using command prompt.
  2. run pip install flask.
  3. run project as python app.py.
  4. copy paste the url of local host like http://120.0.0 and Enter.
